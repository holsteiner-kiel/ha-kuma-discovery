# HA Kuma Discovery 2.1.0

![HA Kuma Discovery](logo.png)

Automatic Home Assistant device discovery for Uptime Kuma.

Version 2.1.0 keeps a stable link between Home Assistant sources and their Uptime
Kuma monitors. Renaming a discovered device or app/add-on now renames and reuses
the same monitor instead of creating a duplicate. Existing installations migrate
automatically from their current monitor names.

See [documentation](DOCS.md) for setup, updates and troubleshooting, and
[changelog](CHANGELOG.md) for version history.
