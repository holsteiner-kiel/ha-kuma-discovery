# HA Kuma Discovery 1.6.0

![HA Kuma Discovery](logo.png)

Automatic Home Assistant device discovery for Uptime Kuma.

Version 1.6.0 refreshes every evaluated Push monitor each cycle, adds native
Homematic IP Connectivity monitoring and hardens optional-integration handling.
The heartbeat window and three-cycle DOWN debounce are preserved. Existing
installations need no new configuration.

See [documentation](DOCS.md) for setup, updates and troubleshooting, and
[changelog](CHANGELOG.md) for version history.
