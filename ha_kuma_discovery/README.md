# HA Kuma Discovery 2.0.0

![HA Kuma Discovery](logo.png)

Automatic Home Assistant device discovery for Uptime Kuma.

Version 2.0.0 downloads a signed, versioned multi-architecture image instead of
building the container locally and adds native AirGradient Ping monitoring.
The heartbeat window, three-cycle DOWN debounce, configuration and persisted
state remain compatible.

See [documentation](DOCS.md) for setup, updates and troubleshooting, and
[changelog](CHANGELOG.md) for version history.
