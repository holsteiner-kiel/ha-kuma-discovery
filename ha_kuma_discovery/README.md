# HA Kuma Discovery 2.0.1

![HA Kuma Discovery](logo.png)

Automatic Home Assistant device discovery for Uptime Kuma.

Version 2.0.1 adds compact Kuma and integration timing diagnostics while retaining
the signed multi-architecture images and AirGradient monitoring introduced in
2.0.0. The heartbeat window, three-cycle DOWN debounce, configuration and
persisted state remain compatible.

See [documentation](DOCS.md) for setup, updates and troubleshooting, and
[changelog](CHANGELOG.md) for version history.
